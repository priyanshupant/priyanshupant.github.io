A little graph experiment

Start with eight isolated vertices. Move the slider to add edges, one at a time.

Drag or use the arrow keys.
Vertices8
Connected components1
Independent cycles0

For an undirected graph, the dimension of the cycle space is m − n + c, where n is the number of vertices, m is the number of edges, and c is the number of connected components.

Made with ordinary HTML, SVG and a few lines of JavaScript. No external libraries.
